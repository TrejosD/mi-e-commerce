# Mi E-commerce

Proyecto hecho por Diego Trejos como practica de HTML Y CSS combinando grid y flexbox.

## Acceso

```
https://trejosd.github.io/mi-e-commerce/
```

## Descripción

La pagina muestra dos secciones principales:

- La seccion principal, tarjetas de productos de una tienda online.
- Menu lateral, para navegar entrar categorias de productos.

El proyecto utiliza assets en local, con botones con estado hover.

## Tecnologias utilizadas

- HTML
- CSS
- Grid
- Flexbox
